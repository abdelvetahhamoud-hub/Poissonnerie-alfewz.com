# مسمكة الفوز — نشر الموقع على Supabase

الملفات:
- `schema.sql`: الجداول والصلاحيات والدوال (يُشغَّل مرة واحدة)
- `index.html`: الموقع كاملاً (عربي / Français / English)
- `_headers`: رؤوس الأمان (HTTPS وCSP وغيرها) للاستضافة

> Supabase هو الخلفية (الحسابات وقاعدة البيانات والصور). ملف `index.html` يحتاج استضافة ثابتة مجانية: Netlify أو Cloudflare Pages أو Vercel أو GitHub Pages. Supabase لا يعرض ملفات HTML.

## الخطوات
1. أنشئ مشروعاً في supabase.com.
2. من **SQL Editor** الصق محتوى `schema.sql` كاملاً واضغط Run.
3. **Authentication → Providers → Phone**: فعّله واختر مزود رسائل SMS (Twilio أو MessageBird أو Vonage). تأكد أن المزود يرسل إلى موريتانيا (+222) وأن رصيدك يكفي. للتجربة استعمل أرقام الاختبار في نفس الصفحة.
   - اجعل مدة الرمز (OTP expiry) 600 ثانية أو أقل، وفعّل CAPTCHA إن أمكن.
4. **Authentication → URL Configuration**: ضع رابط موقعك في Site URL.
5. **Project Settings → API**: انسخ `Project URL` و`anon public key` والصقهما أعلى `index.html` في `SUPABASE_URL` و`SUPABASE_ANON_KEY`.
   - مفتاح `service_role` لا يوضع في الموقع أبداً.
6. ارفع `index.html` و`_headers` إلى الاستضافة.
7. افتح الموقع وسجّل الدخول برقمك مرة واحدة، ثم من SQL Editor شغّل:
   ```sql
   update public.profiles set role = 'owner' where phone = '44631654';
   ```
   (غيّر الرقم إن كان رقم المالك مختلفاً). أعد تحميل الموقع فتظهر ⚙️ لوحة المالك.
8. من لوحة المالك: أضف رقم الدفع (بنكيلي/مصرفي/سداد) وارفع صور المنتجات.

## ما تفرضه قاعدة البيانات (لا المتصفح)
- أرقام +222 فقط تستطيع التسجيل.
- السعر يُحسب في الخادم من جدول المنتجات داخل `create_order`، ولا يُقبل سعر من المتصفح.
- رقم عملية الدفع لا يتكرر، وفاصل 20 ثانية بين طلبات الزبون الواحد، وكميات من 1 إلى 99.
- الزبون يرى طلباته فقط، ولا يستطيع تعديل نجومه أو دوره.
- المنتجات والإعدادات والنجوم وتأكيد الطلبات: المالك فقط.
- إشعارات الدفع في مخزن خاص: كل زبون في مجلده، والمالك فقط يراها.
- سجل تلقائي `audit_log` لتغييرات المنتجات والإعدادات وتأكيد الطلبات.

## ما لا يغطيه هذا الملف
- لا يوجد ربط تلقائي مع بنكيلي أو مصرفي أو سداد. يحوّل الزبون ويرفع الإشعار وتتحقق أنت من المبلغ في تطبيقك قبل التأكيد.
- لا يرسل الموقع رسائل واتساب تلقائية من نفسه. الزبون يضغط الزر ويبدأ المحادثة.
- قبل الإطلاق الفعلي، الموقع فيه مدفوعات وبيانات زبائن، فيُنصح بمراجعة مختص.

## اختبار سريع بعد النشر
1. زبون بدون دخول لا يستطيع إرسال طلب.
2. زبون عادي لا يرى ⚙️ لوحة المالك، وتجربة `update products` من حسابه تفشل.
3. إرسال نفس رقم العملية مرتين يُرفض.
4. المالك يؤكد طلباً فتزيد نجوم الزبون.
